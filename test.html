使用说明

  1. 确保已安装并启用 Arex Chrome Extension
  2. 点击浏览器工具栏中的 Arex 图标
  3. 在弹出的对话框中开启录制开关
  4. 回到此页面，点击上方的测试按钮
  5. 打开开发者工具 (F12) → Network 面板
  6. 查看请求头中是否包含 arex-force-record: true
